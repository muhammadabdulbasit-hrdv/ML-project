# Loan Risk Prediction

## Problem
Predict whether a loan applicant is a credit risk based on financial and personal data.

## Dataset
loan_risk_prediction_dataset.xls

## Approach
- Exploratory Data Analysis (EDA)
- Feature Engineering
- One-Hot Encoding and Label Encoding
- StandardScaler
- Logistic Regression, Naive Bayes, K nearest neighbour, Support Vector Machine and decision tree classifier
- Appended the results in a list named result
- Based on the results choosed the one with the highest accuracy_score and f1_score (SVM has the highest score)

## Results
accuracy_score of SVM: 0.936
f1_score of SVM: 0.84
